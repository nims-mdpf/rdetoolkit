Image output options: `to_png` and `to_jpeg` take a keyword-only `kind`
(`other_image` by default, or `main_image` / `thumbnail`), so a TIF upload can
become the main image. New `copy_file(source_path, out, filename, *, kind)`
copies a file byte for byte into any output directory, and new
`save_image(image, out, filename, *, kind="other_image", channel_order="rgb")`
saves a NumPy array or Pillow image in the format of the filename suffix;
`channel_order="bgr"` writes OpenCV BGR / BGRA arrays like `cv2.imwrite`.
Invalid kinds, filenames, suffixes and channel orders raise before anything is
written (part of #599).
