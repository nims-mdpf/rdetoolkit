Explainable table-format detection in `rdetoolkit.graph`: `detect_table_format(path)` reads
a bounded, read-only sample (at most 64 KiB and 50 rows; files over 1 GiB are rejected
before reading) and returns a `DetectionDecision` with the detected encoding (UTF-8 BOM,
UTF-8, Shift-JIS/cp932), delimiter (comma, tab, semicolon; quotes honoured), every
candidate reader with its confidence and evidence, and the column names and row count
the selected reader produces. `reader="auto"` / `csv_format="auto"` use it when no reader
claims the file suffix and read with the detected encoding and delimiter; an unclear file
(numeric first row, mixed first row, label column under a numeric header, two possible
delimiters) raises `AmbiguousFormatError` naming the candidates and the remedy
(`--csv-format <id>`, `csv_format=<id>`, `reader=<id>`) instead of being guessed.
`rdetoolkit plot --detect` prints the decision and exits without plotting. The legacy
parsers accept keyword-only `encoding` and `delimiter` options (#711).
