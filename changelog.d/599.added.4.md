Input helpers: new `read_lines(path, *, encoding=None, keepends=False)`
returns the lines of a text file decoded like `read_text`; new
`list_excel_sheets(path)` returns the worksheet names in workbook order; new
`detect_encoding(path)` returns the canonical name of the codec the builtin
readers detect. `unzip_inputs` also extracts tar archives, uncompressed or
compressed with gzip, bzip2 or xz, chosen by content rather than suffix; tar
members outside the destination, links and special files are skipped with a
warning. Its documentation now states that ZIP member names without the UTF-8
flag are restored as CP932, unlike v1 code that called `ZipFile.extractall`
(part of #599).
