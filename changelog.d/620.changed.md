The Runner now loads `tasksupport/invoice.schema.json` into the injected
`InvoiceData` in every mode. Before, only ExcelInvoice and SmartTable row tiles
carried it, so `set_custom_fields(invoice, updates)` raised
`ValueError: No invoice schema` in invoice, MultiDataTile and RDEformat mode
unless the flow passed `schema=`. The default now works in all modes; pass
`schema=` only to cast with a different schema (#620).
