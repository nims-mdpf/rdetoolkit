Output options for builtin writers: `save_csv` takes keyword-only `encoding`,
`quoting` (`QUOTE_MINIMAL`, `QUOTE_ALL`, `QUOTE_NONNUMERIC` or `QUOTE_NONE`)
and `lineterminator` (applied to row preambles and the table alike, with the
file encoded once so `utf-8-sig` writes a single BOM); `save_json`
takes `indent` (`None` for one-line output) and `ensure_ascii`; `save_invoice`
takes `indent` and `drop_none`, which omits `None` values and list items
recursively without modifying the input. Default calls write the same bytes
as before. Invalid options and serialization or encoding failures are raised
before any file is written (part of #599).
