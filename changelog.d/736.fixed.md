Fixed type stubs that disagreed with the runtime. `rdetoolkit.domain.magic`
declared `schema_version` with a default that failed type checking, so the
stub was broken for checkers that read it. The stubs for `OutputLayout` and
`TileOutputPaths` now declare them as the frozen dataclasses they are, and the
stubs for `rdetoolkit.runner` and `rdetoolkit.runner.mode_resolver` now declare
`__all__`. Removed the stubs `rdetoolkit.pyi` and `graph/{api,io,parsers,renderers,strategies}.pyi`
and the module `graph/parsers.py`. Each one had a package directory of the same
name, so type checkers and the import system never used it. A stubtest drift
check over `rdetoolkit.graph`, `domain`, `runner` and `modes` now runs in the
test suite, and the built wheels are type-checked in CI (#736).
