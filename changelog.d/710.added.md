Table readers for the graph engine in `rdetoolkit.graph`: a small `TableReader` protocol
(`reader_id`, `extensions`, `read(path) -> TableData`) lets an instrument format be plotted
without editing `ParserFactory`. Readers come from a caller-owned `ReaderRegistry`, the
builtin readers (`standard`, `transpose`, `noheader`, `meta_block`) or the new
`rdetoolkit.graph.readers` entry-point group, in that fixed order; `render_graph` and
`read_table` accept a path with `reader=` (an id, `"auto"` for the reader claiming the file
suffix, or an instance) and `readers=`, and `GraphResult.detection` records which reader was
selected and why. Duplicate ids fail with `DuplicateReaderError` naming both targets, an
unknown id with `UnknownReaderError` listing the available ids, and a plugin that cannot be
loaded with `ReaderPluginError` only when it is requested. Nothing is registered at import
time. `csv2graph(csv_format=...)` and `rdetoolkit plot --csv-format` also accept `auto` and
any registered reader id; their default stays `standard` (#710).
