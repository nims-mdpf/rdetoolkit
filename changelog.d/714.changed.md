The `plot_lines` and `plot_scatter` nodes now share the Graph Engine: the planner
resolves their columns, pairs, frames and series labels, the shared limit validator
checks `xlim`/`ylim`, and the same Matplotlib series primitive as `render_graph`
draws them. Equivalent requests therefore select the same series with the same
labels and data through both APIs. Node ids, signatures, call-log records, output
kinds and images are unchanged, and the nodes still use plain Matplotlib defaults
instead of the csv2graph style. An unknown column now raises `PlotRequestError`
(`reason="unknown_column"`, a `ValueError`) instead of `KeyError`, a column name
carried by several columns raises `reason="ambiguous_column"`, and invalid limits,
including a bound `<= 0` on a `"log"` axis, raise `reason="invalid_axis_limits"`
before any figure exists. `save_figure` keeps saving caller-owned figures without
closing or restyling them. `new_figure(tight_layout=False)` in the Matplotlib
runtime no longer selects the tight layout (#714).
