`render_graph` writes into an RDE `OutputContext` through the new
`OutputContextSink` (overlay images to `main_image`, individual images to
`other_image`, HTML to `struct`; configurable per role), next to `DirectorySink`.
Both are exported from `rdetoolkit.graph` with `ArtifactSink`, `OutputPathError`
and `ArtifactCollisionError`. Images (PNG, SVG, PDF) are produced for overlay and
individual figures and HTML for overlay figures; every other combination, and HTML
without Plotly, is rejected before any file is written. `GraphResult.manifest()`
lists every artifact in plan order by file name and records the table-format
detection as a structured object; the manifest and the HTML bytes are identical for
the same request in different directories (the Plotly div id is derived from the
figure content). HTML now applies the axis limits of the plan, including one-sided
limits and log axes. `IndividualStrategy` writes every non-HTML format of
`OutputConfig.formats` instead of PNG only; the default stays PNG (#720).
