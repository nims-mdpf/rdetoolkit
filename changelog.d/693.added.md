Reusable, opt-in output checks for RDE pytest cases (#693, part of #682):
`rdetoolkit.testing.rde_check(id=...)` attaches a rule ID to a check function
and returns the same function; `rde_case(..., checks=(...))` and
`RdeTestResult.assert_checks(...)` run decorated or plain checks on the
finished run. Checks are never registered or run by production code, do not
change `RunReport.status` or `job.failed`, and every failing check is
reported as `output contract failed` with its rule ID, the dataset, the
artifacts it read (with tile and datatile) and the assertion. When the
processing outcome is not the expected one, the case says the checks were
not run. A check that returns a value instead of raising fails.
See `docs/usage/testing`.
