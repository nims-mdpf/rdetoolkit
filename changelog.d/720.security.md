The graph `PathValidator` decides containment on path components
(`Path.relative_to`) instead of a string prefix, so a symlink inside the output
directory that points into a sibling directory sharing the prefix (for example
`out2` next to `out`) is rejected with the existing "Security violation" message.
`render_graph` sinks use the same rule, and the legacy csv2graph saver checks every
destination before it writes the first file (#720).
