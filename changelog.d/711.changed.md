`ParserFactory.auto_detect` no longer guesses: it uses the new detector, so a headered
file whose first data row is numeric is read with its header (it was read as headerless),
transposed, tab-separated, Shift-JIS and metadata-block files get a matching parser, and
an ambiguous, empty or undecodable file raises `AmbiguousFormatError` or
`InvalidCSVFormatError` instead of returning `NoHeaderParser`. The default of
`csv2graph(csv_format=...)` and `rdetoolkit plot --csv-format` stays `standard` (#711).
