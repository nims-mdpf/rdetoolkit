`set_custom_fields` and `resolve_custom_key` report schema mismatches with their
own error-catalog codes instead of code 1: 4011 `InvoiceCustomKeyUndefined` (key
not under `properties.custom.properties`), 4012 `InvoiceCustomLabelUnknown` (no
field has the label) and 4013 `InvoiceCustomLabelAmbiguous` (more than one field
has it). They are still raised as `StructuredError`, so code that catches it keeps
working, `@flow(error_code=...)` does not remap them, and `job.failed` shows the
code with the catalog remediation. An uncastable value stays code 1 with v1's
message (#621).
