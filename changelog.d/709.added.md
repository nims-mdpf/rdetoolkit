New spec-first graph API in `rdetoolkit.graph`: `render_graph(frames, GraphSpec(...), output=OutputSpec(DirectorySink(...)))`.
A versioned, backend-neutral `GraphSpec` (with `SeriesSpec`, `AxisSpec`, `LegendSpec` and
`StyleSpec`) replaces competing keyword switches (for example `layout` instead of `mode`
plus `no_individual`); `build_plot_plan` resolves it into an immutable `PlotPlan` that
records columns, labels, units, figures, reserved file names and where each decision came
from, and snapshots deterministically with `to_dict()`. `render_graph` returns a
`GraphResult` whose every `Artifact` carries a file path or an in-memory figure, its
format, series ids, labels and diagnostics, plus a machine-independent manifest.
`csv2graph` and `plot_from_dataframe` keep their signatures and return values (#709).
