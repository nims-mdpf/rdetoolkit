**`rdetoolkit run --explain` previews graph inputs (#735).** The
`graph_preview` section, a placeholder until now, reports for every `.csv` and
`.tsv` input of every planned tile how the Graph Engine's builtin table
detection would read it: the selected reader, or `ambiguous` with every
candidate, its confidence and its evidence (reason `sample_not_parseable`
when the bounded sample does not parse, so one such file never aborts the
explanation), or `unreadable`; plus the encoding,
delimiter, column count and data-row count. Detection reads a bounded sample
through a read-only handle. Column names and cell values are never emitted.
Archive members that are extracted only at run time are `skipped`, and the
section is `deferred` when nothing else is tabular. Reader plugins are not
loaded, and the flow's plot settings and rendering are not checked. The
explain schema (`schema_version` `"1"`) gains the optional `checks`,
`not_checked` and `tiles` fields under `graph_preview`; earlier payloads still
validate. The default text output adds a graph section with the remedy for an
ambiguous file, and the CLI reference now documents `--explain` and
`--format`.
