A top-level mapping section of a v1 `tasksupport/rdeconfig.yaml` that is not
a v1 section, such as a template's own `sem:` or `xps:` settings, is read as
`config.custom["<section>"]` without a `UserWarning` (#624). Before, every run
of an unchanged template warned `Legacy configuration key '<section>' is
preserved under custom.` An unknown top-level value that is not a mapping
still warns, and the message now says to move it under `custom:`. A section
named like a v1 section, such as `sytem:`, keeps warning and names the section
it resembles, because its settings are not applied. A v2-form
`rdeconfig.yaml` or `[tool.rdetoolkit]` still rejects unknown sections
(E1002); write template settings there as `custom: {<section>: {...}}`.
