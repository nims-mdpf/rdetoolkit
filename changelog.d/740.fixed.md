The `rdetoolkit` CLI works with typer 0.26 and later, which ship a vendored
copy of click as `typer._click` and no longer depend on the `click` package.
`rdetoolkit.cli.app` no longer imports `click`, so the CLI no longer fails
with `ModuleNotFoundError: No module named 'click'` where only typer is
installed, and its command classes type check against both typer lines (#740).
