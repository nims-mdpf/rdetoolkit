`csv2graph`, `plot_from_dataframe` and `rdetoolkit plot` no longer let two series
overwrite each other's individual figure. File names are reserved for every series
before the first figure is rendered; names that collide case-insensitively (for
example `Voltage` and `voltage`, or `A B` and `A_B`) all get the stable series id
appended (`plot_voltage_s000.png`, `plot_voltage_s001.png`) and a `GraphUserWarning`
is emitted. `/`, `\` and `..` in a header or base name are sanitized instead of
failing after the overlay image was written. Names that do not collide are
unchanged (#708).
