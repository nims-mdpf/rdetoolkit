`rdetoolkit doctor` gains `--strict` (warnings fail with exit 1) and a
repeatable `--module NAME`, which imports a project module and reports the
`rdetoolkit nodes lint` findings under the check `nodes.lint` (for example
E2001 for a duplicate node id, or `ModuleImportFailed`). An `inputdata/`
without any file is now the warning `NoInputFiles` (check `inputs.files`),
consistent with `validate all --require-files`; missing required inputs still
fail. Doctor states that it ran static checks only: the text output says the
flow was not executed, and the JSON adds `"flow_executed": false` and
`"strict"`. Modules are imported only when `--ref` or `--module` names them;
`nodes lint`, `validate all` and `run --validate-only` are unchanged (#697).
