`PlotConfigBuilder.set_figure_size` and `set_matplotlib_params` now take effect:
the built `PlotConfig` carries them as `PlotConfig.style` (a `StyleSpec`, `None` when
neither setter was called), and `MatplotlibRenderer` draws the figure at that size
with those rcParams. `GraphSpec.style` does the same for `render_graph`. Explicit
style is applied over the graph house style, key by key, and only to the figures of
that call: `rcParams` are the same afterwards as after a call without style, and a
returned figure keeps the style when it is saved later. HTML output gets the figure
size (inches x 100 pixels) only when a size was set explicitly. A figure size that is
not a pair of finite numbers greater than zero, an unknown or backend-related rcParam
(`backend`, `backend_fallback`, `interactive`, `toolbar`), or a value an rcParam
rejects raises `PlotRequestError` (`reason="invalid_figure_size"` or
`"invalid_rc_param"`) before any figure is created; the builder setters themselves
still accept any value. Without these settings the output is unchanged (#716).
