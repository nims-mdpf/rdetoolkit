**`rdetoolkit run --explain` previews magic variable resolution (#727).** The
`magic_preview` section now reports, per planned tile, the syntax, source
resolution, normalization and output-limit diagnostics of `${...}` templates
against the pre-flow invoice snapshot. Metadata expressions are `deferred`
because the flow produces `metadata.json`, and tiles whose invoice is built from
a table row (SmartTable, ExcelInvoice) are `deferred`. Source values are never
emitted. The preview does not check the invoice schema, `InvoiceValidator`
checks, or anything the flow changes, so a resolved preview does not guarantee
successful registration. `preview_invoice` gains `deferred_scopes` for callers
whose sources are not yet available.
