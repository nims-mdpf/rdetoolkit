Input options for builtin readers: `read_text` takes a keyword-only
`encoding`; `read_csv_with_header` takes keyword-only `encoding`, `skiprows`
and `header` (default `"infer"`, so `names=` without `header` reads every row
as data, as in pandas) and passes further `pandas.read_csv` options such as
`sep`, `dtype=str` and `keep_default_na=False` through. An explicit encoding
is applied strictly: a decoding error is raised, never answered by another
codec; without it the existing detection is unchanged. `iterator` and
`chunksize` are refused with `ValueError`, since the node always returns a
DataFrame. `read_excel` formally supports `sheet_name=None` and lists of sheet
names and positions, returning a dict keyed like pandas, and its overloaded
signature types a single sheet as a DataFrame and `None` or a list as a dict.
Default calls behave as before (part of #599).
