`csv2graph`, `plot_from_dataframe` and `rdetoolkit plot` reject an unsupported
`mode` with `PlotRequestError` (a `PlotConfigError` that is also a `ValueError`,
`reason="invalid_mode"`) instead of silently plotting individual figures, and
reject `mode="individual"` combined with `no_individual=True` (CLI:
`--mode individual --no-individual`, exit code 2) instead of finishing without
output. Both fail before any file or directory is created (#707).
