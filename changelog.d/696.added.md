`rdetoolkit validate all --require-files` fails (exit 1) when no standard RDE
file was found to validate, so a CI job cannot pass after validating nothing
because of a wrong path or an incomplete checkout. The failure has the error
type `no_target_files` in both text and JSON output (one more entry in the
usual JSON array) and lists the searched directories with a remediation. A
deprecation notice for the v1 `templates/` layout does not count as a
validated file. Without the flag, finding nothing still exits 0, and
`--strict` alone still only makes warnings fail. The documented CI form is
`rdetoolkit validate all --strict --require-files` (#696).
