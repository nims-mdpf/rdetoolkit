A release gate for rendering resources and multi-tile throughput. `scripts/bench_ga.py`
benchmarks 1, 10, 100 and 1000 Y-series renders, repeated renders, CSV detection and
parsing, and tile planning and runs over large SmartTable, ExcelInvoice and
MultiDataTile batches. It runs each case in its own process and records the hardware,
Python and dependency versions, data sizes, commands and results (time, peak RSS,
figures left alive, image and tile counts, artifact manifest digest). The new
`v2 GA benchmark` workflow runs it against a clean wheel installation and fails when a
metric exceeds its threshold against `scripts/bench_ga_baseline.json`, or when a render
leaves a figure alive. Fast smoke tests in `tests/v2/perf/` check that repeated renders
release every figure, that the artifact manifest is deterministic, and that a 100-row
SmartTable run keeps the continue and fail_fast contracts and cleans up after an
interruption. All inputs are synthetic (#739).
