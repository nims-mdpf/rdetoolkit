A GA release gate for cross-mode diagnostics: `tests/v2/ga/` runs both
entries (v2 flow and v1 dataset callback) on all five modes for success,
pre-/post-validation failure, `StructuredError`, plain exceptions, strict
argument rejection, publication failure, error policy, in-flight events,
the pytest helpers and state isolation across runs, against the frozen v1
observations. `tests/v2/ga/matrix.yaml` lists every entry x mode x outcome
cell as covered by named tests or excluded with a rationale, and a test
fails on any gap; `docs/ga_debuggability_contract.md` documents the
contract, the intentional v1 differences and the executed mutation probes
(#698).
