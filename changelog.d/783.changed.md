On the v1 callback entry, a plain exception raised by the dataset callback
outside any node call still writes `ErrorCode=3001`, but the message now
names the callback instead of a node call:
`Dataset callback <module>.<qualname> failed (<ExceptionType>): <message> Remediation: ...`.
Before, it read `Node execution failed for call unknown: ...` and pointed at a
call-log entry the callback does not have. A `StructuredError` keeps its own
code and message, and a failure inside a node the callback calls still names
that call's id (#783).
