A run that fails in post-validation (an invalid tile `metadata.json` or
invoice, 4001/4002/4003) no longer drops its executed tiles from the run
report. The report is `failed` with the validation error, keeps every tile
and node call summary with the status it ran with, and `report show` and
`report trace` can still read them. `job.failed`, the run report schema and
the shape of pre-validation, tile-failure, partial and successful runs are
unchanged (#685).
