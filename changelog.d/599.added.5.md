New `describe_features(invoice, metadata, metadef_path)` returns a copy of the
invoice whose `basic.description` has the `_feature` metadata lines appended
with the formatting of the Runner's `feature_description` step, for programs
that write the description themselves. Set `system.feature_description: false`
when a flow saves the result, so the Runner does not append the lines again
(part of #599).
