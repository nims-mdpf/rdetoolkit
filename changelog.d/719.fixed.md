`csv2graph`, `plot_from_dataframe`, `rdetoolkit plot` and `render_graph` apply
one-sided axis limits: `xlim=(0, None)` fixes only the lower bound and
`ylim=(None, 10)` only the upper bound, while the other side keeps Matplotlib's
automatic limit, matching the `plot_lines` node. Previously a one-sided limit was
silently dropped. The CLI gains `--xmin`, `--xmax`, `--ymin` and `--ymax`. Every
entry point validates limits with the same rule: a non-finite bound, equal bounds,
or a bound `<= 0` on a log axis raise `PlotRequestError`
(`reason="invalid_axis_limits"`, exit code 2 on the CLI) before anything is
written; reversed bounds still invert the axis. `normalize_axis_limits` is
unchanged (#719).
