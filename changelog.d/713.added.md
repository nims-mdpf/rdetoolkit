Graph renderers are injectable: `render_graph(..., renderers=RendererRegistry([...]))`
selects, for every artifact, the first registered renderer whose declared
`RendererCapabilities` (formats, figure kinds, optional modules, install hint) cover
its format and figure kind. A renderer is any object implementing the
`GraphRenderer` protocol (`capabilities`, `render`, `export`, `close`), so a custom
engine can be supplied without patching rdetoolkit; `MatplotlibRenderer` (PNG, SVG,
PDF) and `PlotlyRenderer` (overlay HTML) implement it. `builtin_renderers()` returns a
new registry with new renderer instances on every call and nothing is registered at
import time. `render_graph` now writes overlay HTML through Plotly. An unsupported
format, HTML for individual figures, or a missing Plotly raises
`UnsupportedFormatError` or `RendererUnavailableError` (an `ImportError` naming
`pip install "rdetoolkit[plotly]"`) before any file or directory is created; with
`html=True`, `csv2graph` and `plot_from_dataframe` check Plotly before drawing
anything. Explicit `StyleSpec.rc_params` that the HTML renderer cannot apply are
reported as a `style_ignored` diagnostic on the HTML artifact (#713).
