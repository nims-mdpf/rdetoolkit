`rdetoolkit test [PATH] [PYTEST_ARGS]...` (#694, part of #682): a thin
wrapper that runs `python -m pytest` with every argument forwarded unchanged
and exits with pytest's exit code; plain `pytest` stays fully equivalent and
recommended for CI. pytest is now available as the optional extra
`rdetoolkit[testing]` and is still not a runtime dependency; without it the
command prints an installation hint and exits 2. The rdetoolkit pytest plugin
adds an `rdetoolkit: retained runs` section (data root, run report, diagnostics
sidecar, `job.failed`) to the report of a failing test that used
`rde_runner` or `rde_run`.
